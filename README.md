# Softkit

Softkit builds focused creative tools for makers who want less friction and more flow.

## Products

### QuickCut
Video editing for short-form creators. Cut, arrange, and export without the bloat of a full NLE.

- Website: [softkit.web.app/quickcut](https://softkit.web.app/quickcut/)
- Issues: use the **QuickCut** product label when filing

### ArtKit
A lightweight art and illustration workspace (formerly DuoArt). Sketch, compose, and ship assets quickly.

- App / site: [softkit-artkit.web.app](https://softkit-artkit.web.app)
- Website: [softkit.web.app/artkit](https://softkit.web.app/artkit/)
- Issues: use the **ArtKit** product label when filing

## Community & support

This repository is the **public home for Softkit community issues** — bug reports, feature ideas, and source-access requests.

Open an issue using one of the templates:

| Template | When to use |
| --- | --- |
| [Bug report](https://github.com/jeromelacote/softkit/issues/new?template=bug_report.yml) | Something is broken or unexpected |
| [Feature request](https://github.com/jeromelacote/softkit/issues/new?template=feature_request.yml) | Suggest an improvement |
| [Source access](https://github.com/jeromelacote/softkit/issues/new?template=source_access.yml) | Request access to private source |

Please pick the product (**QuickCut**, **ArtKit**, or **website**) when filing so we can triage quickly.

Website: [softkit.web.app](https://softkit.web.app)  
Email: [support@victorise.com](mailto:support@victorise.com)
